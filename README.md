# 🎓 AI Viva Study Assistant

An AI-powered engineering viva preparation assistant.

## Features

- 📘 Study Mode
- 📝 Practice Mode
- 🎤 Mock Viva Mode
- 📊 AI Answer Evaluation
- 🤖 Topic-wise Viva Questions

## Tech Stack

- Python
- Streamlit
- Groq API
- Llama Model

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run project:

```bash
streamlit run app.py
```
